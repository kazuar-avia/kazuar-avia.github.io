# Map icon attribution

The map uses aircraft silhouettes adapted from the [VATSIM Radar contributors](https://github.com/VATSIM-Radar/vatsim-radar/tree/9e70c08da081d8c8678c68d4052b3befc075959c/app/assets/icons) under [CC BY-NC 4.0](https://github.com/VATSIM-Radar/vatsim-radar/blob/9e70c08da081d8c8678c68d4052b3befc075959c/LICENSE).

Kazuar recolors and rasterizes the artwork for the live map. The map adds outlines, inner shading, and sizing for its circular markers. Some aircraft types use a related silhouette when VATSIM Radar has no exact match.

SU95, IL18, and special symbols without a VATSIM Radar equivalent use the map’s earlier artwork.
